# Железо и особенности Pi 5

[English](hardware.md) · **Русский**

## Конфигурация автора (на ней всё проверено)

| | |
|---|---|
| Плата | Raspberry Pi 5, 4 ГБ |
| ОС | Raspberry Pi OS trixie **64-bit**, ядро `kernel8.img` (страницы 4 КБ) |
| Экран | 7" HDMI 1280×800 на **HDMI-A-2**, вверх ногами: `video=HDMI-A-2:1280x800@60,rotate=180` |
| Тач | USB, QinHeng `1a86:e5e3`, настоящий multitouch |
| Контроллеры | DDJ-FLX4 (карта `DDJFLX4`), DDJ-GRV6 (карта `DDJGRV6`) |

## Что важно на Pi 5

- **Страницы 4 КБ.** Прошивка Pi 5 по умолчанию грузит `kernel_2712.img` (16 КБ).
  chroot XDJ-RX3 (glibc 2.13) рассчитан на 4 КБ, поэтому `make pi-setup` добавляет
  в `config.txt` выше финального `[all]`:
  ```
  [pi5]
  kernel=kernel8.img
  ```
  Проверка: `getconf PAGESIZE` → `4096`.
- **16 bpp.** При 32 bpp ядро падает (oops в `iommu_dma_mmap`), когда `rbp` делает
  mmap `/dev/fb0`, и экран остаётся чёрным. В `rb.conf` по умолчанию стоит
  `RB_FB_LIE_BPP=16`, менять не нужно. Косметика: у правого края полосы волны
  несколько бледных пикселей.
- **64-битная ОС подходит.** 32-битный soft-float chroot исполняется на 64-битном
  ядре (32-bit EL0); `install.sh` проверяет это при установке.
- **Питание USB.** С официальным БП 27 Вт порты отдают суммарно 1,6 А, без него —
  0,6 А. FLX4 питается от шины, поэтому нужен этот БП (или хаб с питанием).
  **GRV6 — только от своего адаптера.**
- **FLX4 при загрузке: виноват загрузчик.** Со включённой сетевой установкой (так
  по умолчанию на Pi 5) загрузчик при включении опрашивает USB в поисках сочетания
  клавиш, и после этого DDJ-FLX4 «зависает»: его порт пуст и после холодного
  старта, и после перезагрузки, пока у пульта не пропадёт питание (замерено
  2026-10-26). `make pi-setup` ставит в EEPROM загрузчика
  **`NET_INSTALL_ENABLED=0`** (старая настройка — в
  `/var/lib/rbpi5/eeprom.conf.sdj-bak`); с ней FLX4 определяется на 0,94 с в обоих
  случаях. Вручную: `sudo rpi-eeprom-config > e.conf; echo NET_INSTALL_ENABLED=0 >>
  e.conf; sudo rpi-eeprom-config --apply e.conf`, затем перезагрузка. Цена: при
  включении нельзя вызвать экран сетевой установки с USB-клавиатуры.
  `BOOT_NET_INSTALL=1` в `pi.env` не трогает EEPROM; тогда запасной вариант —
  `USB_POWERCYCLE=1` (`rblive4-usb.service`: один раз при загрузке выключает питание
  всех корневых хабов, `uhubctl`), при этом гаснет и экран, питающийся от USB Pi.
- **PipeWire** при входе по SSH захватывает MIDI и звук пульта. `make pi-setup`
  маскирует его пользовательские юниты.
- **Нет звука по HDMI**: зеркало звука на HDMI выключено (`RB_AUDIO_MIRROR_DEV=""`).
- **Другое разрешение экрана.** `rbp` рисует 1280×800 и масштабируется под экран.
  При уменьшении до 0,75× и ниже теряются тонкие линии и штрихи шрифта, на 800×480
  будет мелко.

## Что измерено, а что нет

| | |
|---|---|
| FLX4: звук, контролы, LED, флешка, тач | работает (2026-10-23) |
| GRV6: звук, контролы, LED, индикатор в центре джога, CFX, QUANTIZE | работает (2026-10-23) |
| Плавность индикатора джога GRV6 на 100 Гц | **не подтверждено** |
| Сеты ≥ 1 ч на каждом пульте без перезапуска, xrun и зависаний | **не подтверждено** |
| DSI-панели, панели других разрешений | **не проверялось** |
| 32-битная Pi OS Lite на Pi 5 | **не проверялось** этим комплектом (bring-up upstream на Pi 5 шёл на ней [stableneo]) |

Полная запись bring-up на Pi 5 — [docs/port/pi5-bringup.md](../port/pi5-bringup.md),
на Pi 4 — [docs/13-raspberrypi4.md](../13-raspberrypi4.md).
